## 🚀 Vercel Analytics

This project is configured with Vercel Web Analytics to track visitor metrics and page performance.

### Setup Instructions

1. **Deploy to Vercel**: Connect this repository to Vercel for deployment
2. **Enable Analytics**: In your Vercel dashboard:
   - Go to your project settings
   - Navigate to the "Analytics" tab
   - Click "Enable Web Analytics"
3. **Deploy**: Push changes or trigger a new deployment

The analytics script is already integrated in `index.html` and will automatically start tracking once:
- The site is deployed on Vercel
- Web Analytics is enabled in the Vercel dashboard

### Analytics Features
- Real-time visitor tracking
- Page view metrics
- Performance monitoring
- Device and browser analytics
- Geographic data

## 📦 Installation

```bash
npm install
```

This installs the `@vercel/analytics` package required for web analytics functionality.

## 🛠️ Development

```bash
npm run dev
```

This starts a local development server on port 8000.
